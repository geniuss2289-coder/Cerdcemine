# ‹СЕРДЦЕ› — заготовка сайта майнкрафт-сервера

Статический сайт без сборки: открывается двойным кликом по `index.html`
(или через `node serve.js` → http://localhost:4173). Переход между страницами
с анимацией работает и с двойного клика, и по http; встроенный html2canvas
лежит локально в `vendor/shot.js`.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | главная: герой-мир, бегущая строка, режимы, цифры, правила-табы, «как зайти» |
| `donate.html` | донат: герой с лягушкой на кувшинке, 4 лягушки по биомам, привилегии, сундук, FAQ |
| `styles.css` | общие токены (палитра/шрифты), навигация, секции главной, адаптив |
| `transition.css` + `transition.js` | анимация перехода: лягушка прыгает из nav, кадр страницы уходит в туман |
| `frog.css` + `frog.js` | лягушка в стиле Minecraft: сетка 11×9, каждая клетка — грань блока 3D-модели (верх/перед/бок), поэтому она объёмная |
| `donate.css` + `donate.js` | вёрстка доната, кваканье (Web Audio), выбор привилегии, сундук с призом раз в день |
| `main.js` | канвас-пейзаж на главной, прицел-курсор, reveal, счётчики, табы, копирование IP, онлайн |
| `serve.js` | крошечный локальный сервер на Node |

## Что поменять под себя (чаще всего)

- **Название и IP.** `‹СЕРДЦЕ›` и `play.serdce.mc` встречаются в `index.html`, `donate.html` и `styles.css`.
- **Онлайн.** В `main.js` блок «реальный онлайн»: старт 11 253 из 20 000, цель дрейфует
  в пределах 11 100–11 450, шаг 1–9 каждые ~0.9 с, редкий всплеск до ~12 400.
  Для настоящего онлайна замените это на запрос к `https://api.mcsrvstat.us/2/play.serdce.mc` → `data.players.online`.
- **Цифры на главной.** `data-count` / `data-suffix` у `.stat-num`.
- **Привилегии и цены.** `index.html`-флаг не нужен: карточки в `donate.html` (`data-price`),
  а подписы «до следующей» и прогресс — массив `RANKS` в `donate.js`.
- **Палитра.** `--glow` (рассвет/золото), `--eye` (неоновый лайм), `--ember` (искры), `--sky-*` — только главная,
  донат перекрывает `background` в `.page-donate` (`donate.css`).
- **Шрифты.** Unbounded (заголовки), IBM Plex Sans (текст), IBM Plex Mono (мелочь) — подключены с Google Fonts.

## Анимации

- **переход между страницами:** лягушка из кнопки «Донат» прыгает в центр экрана, а кадр уходящей страницы
  тонет в болотном тумане; новая страница расходится из тумана снизу. Естественное ощущение «прыжка»,
  никакого белого мига. При `prefers-reduced-motion` переход мгновенный.
- **лягушки:** пиксельные, «дышат», моргают, квакают звуком из Web Audio (без файлов), прыгают по клику.
  Три биома как в игре (умеренная / тёплая / холодная) + золотая пасхалка.
- **главная:** пиксельный мир на `<canvas>`, заголовок выезжает построчно, курсор-прицел, счётчики, табы.
