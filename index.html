От скачивания до первого блока

Три шага. Если что-то не вышло — напиши в дискорд, поможем.

  1. Шаг 1

    Открой Java Edition 1.21

    Подойдёт любой лицензионный и нелицензионный клиент на 1.20+. Bedrock-версия тоже работает по тому же адресу.

  2. Шаг 2

    Добавь сервер по IP

    Меню «Сетевая игра» → «Добавить сервер» → впиши play.serdce.mc. Пинг должен быть зелёным.

  3. Шаг 3

    Заходи и читай /help

    Новичкам выдаётся стартовый набор и 500 монет. Всё остальное — в игре.
